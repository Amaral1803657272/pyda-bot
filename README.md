# ⚡ Pyda Bot v3.7 (Cassino & OSINT Pro)

> Bot multifuncional para WhatsApp desenvolvido em JavaScript (Node.js) utilizando a biblioteca Baileys. Possui suporte a jogos de cassino, automação de respostas (Autoresponder), ferramentas de OSINT e utilitários de grupo.

---

## 🚀 Funcionalidades

* 🎲 **Sistema de Cassino & Jogos:** Foguete (Crash), Tigrinho, Roleta, 21 (Blackjack), Cara ou Coroa e Dado.
* 🤖 **Autoresponder Inteligente:** Cadastre e gerencie gatilhos com respostas automáticas diretamente pelo WhatsApp.
* 🔍 **Ferramentas OSINT:** Consultas de IP, CNPJ, CEP, DNS, WHOIS, Subdomínios, Fabricante de MAC e mais.
* 📥 **Downloads & Utilitários:** Revelar mídias de visualização única, downloads de mídias e utilitários de grupo.
* 💰 **Economia Interna (RPG):** Sistema de carteira, banco e trabalho com cooldown.

---

## 🛠️ Como Rodar o Bot (Passo a Passo)

### Pró-requisitos
Certifique-se de ter o **Node.js** e o **Git** instalados no seu ambiente (Termux, Linux ou VPS).

### 1. Clonar o repositório
```bash
git clone [https://github.com/Amaral1803657272/pyda-bot.git]
cd pyda-bot
2. Instalar as dependências
npm install
3. Iniciar o Bot
node index.js
